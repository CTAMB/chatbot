#Chatbot OpenAI

Chatbot utilisant l'API d'OpenAI, a comme possibilité de rechercher le nombre de fois qu'un mot est utilisé.

## Fonctionnalités
- Chatbot

## Commandes
-/help : affiche toutes les commandes du chatbot

## Comment fonctionne le tool calling
1. Création d'une variable tools avec ses parametres.
2. Rédaction de la description (ce que l'on attends de l'outil).
3. Rédaction de l'appel du programme.
4. Execution du programme.
5. Renvoie du résultat avec call_id, réponse du modèle.
